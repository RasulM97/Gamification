# N3.1 RTL, typography and localization hardening

Scope: frontend only. No localization architecture rebuild, backend changes,
database migration, history rewrite, product redesign or N4 work.

## Source classification

| Source | Classification | Treatment |
| --- | --- | --- |
| TaskDrawer contribution timestamp `cycle` | System UI | Existing `task.whenCycle` |
| Activity cycle abbreviation `c` | System UI | Existing `task.row.cycle` |
| Admin demo-controls explanation | System UI | New `admin.demoStorageNote`, all 10 locales |
| Notice category | Typed `NotifCategory` system metadata | Display-time mapping: Tasks, Reviews, Rewards, Economy reuse common keys; Assignments uses new `notification.category.assignments` |
| Notice body `text` | Stored human-readable historical prose | Preserved byte-for-byte |
| Activity `action`, `object`, `reason`, `econ` | Stored historical prose / authored fields | Preserved; existing recognized display helpers retained |
| Cycle outcomes / notice levels | Canonical codes | Existing localized display mappings retained |
| Reward names/descriptions/custom categories | Company authored | Preserved with natural direction |
| Task title/description, notes, reasons, names, files, URLs | Authored content | Preserved; natural direction also applied to editing controls |

**STRUCTURED HISTORY DEBT = YES.** `Act.action` is stored as a string rather than
a stable action code plus localization parameters. “Marcus Webb approved work”,
handoff and redemption prose cannot be safely translated as complete structured
events. Notice bodies have the same limitation. Notice categories are a typed
union and therefore do not belong in this debt bucket. No persisted history was
modified, migrated or translated server-side.

New keys:

- `admin.demoStorageNote` → Demo data is saved in this browser. Reset restores the original demo data.
- `notification.category.assignments` → Assignments

## Layout and typography

Physical inline margins, padding, borders, alignment and positioned affordances
now use CSS logical properties. Sidebar collapse and overlay breakpoints agree
at 980px, and the off-canvas sidebar moves toward the correct edge in RTL.
Drawer entrance motion and only semantic horizontal chevrons adapt direction.
Bell/theme/status icons remain unchanged.

Topbar height accommodates wrapped controls; panels, tabs, metadata and reward
footers wrap; grid tracks and form controls can shrink within their containers.
Tables keep their existing internal horizontal scrolling. No document-level
overflow masking was added. Coins isolate their icon/sign/number sequence; user
text continues to resolve its own direction. Links use the theme's readable
accent. Modal overflow respects rounded edges and the existing scrollable body.

Root-language stacks select self-hosted Vazirmatn, Noto Sans Arabic, Hebrew,
Devanagari, SC, JP and KR. Script-specific tight headings/badges get extra line
height without globally increasing font size. Latin/Russian/Turkish retain
Geist. Font provenance, licenses, subset counts and bytes are documented in
`public/fonts/n31/README.md`.
